Project overview

This project builds the essential components of a feed-forward neural network without using a machine-learning framework for the core model. NumPy handles matrix operations, while gradients and parameter updates are implemented manually.

Dense layers

Fully connected transformations using Z = XW + b, with He weight initialization.

Forward propagation

Data passes through dense layers and ReLU activations to produce class probabilities with Softmax.

Backpropagation

The chain rule computes gradients for weights and biases, starting from Softmax plus cross-entropy.

Mini-batch SGD

Shuffled mini-batches are used to calculate gradients and update trainable parameters.

Gradient checking

Analytical derivatives are compared with central finite-difference estimates on a small synthetic batch.

PyTorch comparison

A separate PyTorch model provides a framework-based reference; it is not used by the NumPy model.

Model data flow

28 × 28 image→Flatten · 784→Dense 128 + ReLU→Dense 64 + ReLU→Dense 10→Softmax

Run the project

  1. Open Google Colab.
  2. Upload MLP_From_Scratch_MNIST_Bluebook.ipynb.
  3. Run the notebook cells in order.
  4. Allow the MNIST files to download when the loader runs.
  5. Run the NumPy training experiment and review the printed metrics.
  6. Optionally run the separate PyTorch comparison cell.

A GPU is optional. The core NumPy implementation runs on CPU; a GPU runtime does not automatically accelerate NumPy calculations.
